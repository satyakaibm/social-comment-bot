This page describes how the Content My Trip Social Comment Studio ("the Service") handles data. The Service is an internal tool that reads comments on our own YouTube channel, Facebook Page, and Instagram professional account, drafts reply suggestions, and publishes replies after review.

What data we collect

For each public comment on our own posts/videos, we store:

  • The comment's public author name/handle and platform-assigned ID
  • The text of the comment
  • The post, video, or media item the comment was made on, and its title
  • The comment's publish timestamp
  • A drafted reply (generated automatically) and, if approved, the reply actually posted

We do not collect private messages, email addresses, phone numbers, precise location, or any data beyond what a platform already makes publicly visible on our own content.

Dashboard operator accounts (for staff who review and approve replies) store a username and a securely hashed password. Plaintext passwords are never stored.

How we use this data

  • To draft a suggested reply to a public comment using an AI language model
  • To let a human operator review, edit, approve, or reject that draft before anything is posted
  • To publish the approved reply back to the same platform, and to "like" the original comment where supported
  • To avoid replying twice to the same comment

Third parties we share data with

  • Google Gemini API — the comment's text is sent to Google's Gemini API solely to generate a suggested reply. See Google's Gemini API terms.
  • Meta Graph API (Facebook/Instagram) and YouTube Data API — used only to read comments on our own content and to publish approved replies to those same platforms.

We do not sell data, use it for advertising, or share it with any party beyond what's listed above.

Data retention

Comment data is kept for as long as needed to avoid duplicate replies and to show reply history in our internal dashboard. We periodically remove the stored text of comments that have already been handled (posted, rejected, or already replied to), while keeping a minimal record (comment ID and status) so the same comment is never processed twice.

Your choices

If you commented on one of our posts and want your comment's stored text removed from our system, contact us using the details below and we will remove it.

Changes to this policy

We may update this policy as the Service changes. The "Last updated" date above reflects the most recent revision.

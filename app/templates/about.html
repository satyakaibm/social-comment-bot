What this is

This dashboard shows every comment the bot has spotted on YouTube, Facebook, and Instagram, what it wrote back, and whether that reply actually got posted. It's also where you go to fix anything that didn't go out on the first try.

Switching platforms and channels

The buttons near the top let you look at one platform at a time — YouTube, Facebook, or Instagram — or all of them together. If more than one page or channel is connected for a platform, a second row of buttons lets you pick between those too. Everything else on the page follows whatever you've selected here.

Activity numbers

Pick a time range — the last hour, day, week, or year — to see how the bot has been doing lately:

  • Comments found — every comment that came in during that time.
  • Bot replies sent — how many of those the bot actually answered.
  • Had a reply already — comments someone had already replied to, so the bot left them alone.
  • Comments taken care of — replies sent plus ones that already had a reply. In other words, the ones that needed no further attention.

API usage (quota)

Each platform only allows a certain amount of activity per day, so this shows how much of that allowance has been used and how much is left, once you've picked a single platform. YouTube resets once a day; Facebook and Instagram set their own limit as we go, so that number can move around. A dash just means nothing has been used yet — not a problem.

Likes, comments & shares

A simple table of how each video or post is doing, refreshed automatically every so often. This is about how well the content itself is performing, not about the bot's replies.

What each status means

Click any of the six tiles on the dashboard to see only comments in that state:

StatusMeaning
Pending reviewA reply is ready but waiting — usually so someone can look it over first.
PostingThe reply is being sent right now. This only lasts a moment.
PostedThe reply went out successfully. This is what you'll see most.
FailedSomething went wrong trying to post it. You can try again — see "Retrying a reply" below.
Already repliedSomeone had already replied, so the bot didn't post a second time.
RejectedThe bot chose not to reply — for example, the comment was too old, or it kept failing and gave up.

The comment list

Every comment matching your current filters shows up here, with these columns:

  • Comment ID / Content ID — the platform's own reference numbers, mostly useful for looking something up directly on YouTube, Facebook, or Instagram.
  • Platform & content title — where the comment was left, and on what video or post.
  • Author & comment — who wrote it, and what they said.
  • Status — one of the six outcomes above.
  • Draft reply — what the bot wrote (or tried to post).
  • Error — the reason it failed, shown only when it did.
  • Dates — when the comment was published, first seen, and posted.

Use the search box to find something by comment text, author, reply, or video title.

Retrying a failed reply

Only failed comments can be retried — new comments are already handled automatically.

  1. One comment: open the Failed tile, fix the draft reply if needed, and click Retry reply.
  2. Several at once: from the same view, click Retry failed replies to have the bot try every failed comment again in the background. Refresh the page after a moment to see the result.

Your account

Click your initial in the top-right corner to find:

  • My Profile — your display name and email.
  • Reset password — change your password. This signs you out everywhere, so you'll need to log back in.
  • Gateway Health — a quick status check for the part of the bot that receives Facebook and Instagram comments.

Where this runs

The dashboard lives on its own computer in the cloud, not on anyone's laptop — so it keeps working even if everyone's laptops are turned off or restarted. Your browser reaches it through a secure connection that doesn't require opening that computer up to the internet at large.

If that cloud computer ever needs to restart, the dashboard switches itself back on automatically — nobody has to log in and start anything by hand.

Updates to the bot go out through a separate tool that a person starts on purpose — it double-checks everything still works, then sends the update to the cloud computer. It no longer happens automatically the moment code changes are merged; someone chooses when an update goes out.

Only one copy of this dashboard should ever be running. Two copies would each keep their own separate record of what's been replied to, and could end up replying to the same comment twice.
